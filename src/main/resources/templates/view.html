Camada View: Server-Side Rendering com Thymeleaf

A View transforma os atributos recebidos do Controller em um documento HTML, sem buscar, alterar ou decidir sobre os dados.

  • View
  • Server-Side Rendering
  • Data Binding

1. Fundamentação teórica

No Server-Side Rendering (SSR), o documento HTML é composto no servidor a cada requisição. O cliente recebe marcação completa e a exibe diretamente, o que simplifica a camada de apresentação e favorece a indexação e o tempo até o primeiro conteúdo visível.

💡 Conceito Teórico: Data Binding unidirecional

Neste projeto, os dados fluem em um único sentido, do Model para o template. O Thymeleaf avalia expressões ${...} contra os atributos da requisição e incorpora os resultados ao HTML. Alterações no navegador não se propagam de volta ao Model.

3. Do template ao documento final

O arquivo-fonte contém atributos th:* e conteúdo de exemplo; o navegador recebe apenas HTML padrão.

🔍 O que ocorre no Servidor?

O ThymeleafViewResolver localiza o template pelo nome lógico retornado pelo Controller. O motor analisa o arquivo, executa os processadores dos atributos th:* e serializa o resultado como HTML, que é enviado na resposta.

💡 Conceito Teórico: Natural Templates

O template permanece um HTML válido quando aberto diretamente no navegador, exibindo o conteúdo de exemplo. Isso permite que o trabalho de design e o de programação ocorram sobre o mesmo artefato.

4. Atributos do Thymeleaf utilizados

AtributoSemânticaOcorrência no projeto
th:textSubstitui o conteúdo da tag pelo valor da expressão, com escape de caracteres HTML.Título e descrição dos cartões.
th:eachItera sobre uma coleção, replicando o elemento para cada item.Cartões das camadas e linhas da tabela de dados.
th:replaceSubstitui o elemento por um fragmento reutilizável.Cabeçalho, rodapé e importações, definidos em layout.html.
th:if / th:unlessRenderiza o bloco condicionalmente.Avisos de coleção vazia.
th:hrefResolve URLs relativas ao contexto da aplicação.Links de navegação.
th:classappendAcrescenta classes CSS conforme uma condição.Destaque do item ativo no menu.
⚠️ Observação Técnica: escape de saída

O atributo th:text escapa caracteres especiais, o que mitiga ataques de Cross-Site Scripting (XSS). O atributo th:utext não realiza esse escape e deve ser evitado com dados de origem não confiável.
